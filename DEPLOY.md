# Запуск «Личного дела» на рег.ру

Почему раньше требовался VPN: голоса хранились на сервере `*.chatgpt.site` (хостинг OpenAI),
а OpenAI не обслуживает российские адреса. Теперь сервер голосования — свой (`api/index.php`)
и живёт на том же хостинге, что и сайт, поэтому всё работает из России без VPN.

## 1. Что купить на reg.ru

1. **Домен** — например, `lichnoe-delo-show.ru` (любое свободное имя в зоне .ru).
2. **Виртуальный хостинг с PHP** — подойдёт самый младший тариф **кроме Host-Lite**
   (в Host-Lite нет PHP). При заказе привязать к нему купленный домен.
   SSL-сертификат Let's Encrypt на хостинге бесплатный.

База данных не нужна: голоса хранятся в файле.

## 2. Настройка в панели (ispmanager)

1. «Сайты» → у сайта выставить **PHP 8.x** (подойдёт любая версия от 7.4).
2. «SSL-сертификаты» → выпустить бесплатный Let's Encrypt для домена (и `www.`).
3. Дождаться, пока домен начнёт открываться (DNS обновляется до суток, обычно быстрее).

## 3. Загрузка файлов

Загрузить в папку сайта (обычно `www/<домен>/`) всё, **кроме**: `.git`, `.github`, `*.md`.

Структура на хостинге:

```
www/<домен>/
  index.html  .htaccess
  assets/  img/
  api/  index.php  .htaccess  config.php   ← создать из config.sample.php
```

Создать `api/config.php` (скопировать `config.sample.php`) и вписать код ведущих:

```php
'admin_pin' => '1234',   // свой код, не этот
```

Голоса сервер сам сохранит в папку `www/lichnoe-delo-data/` — рядом с сайтом, вне доступа из браузера.

## 4. Проверка

| Что открыть | Что должно быть |
|---|---|
| `https://<домен>/api/index.php?a=state` | строка вида `{"votes":{"psychology":0,...` |
| `https://<домен>/` | сайт; нажать карточку → «Голос учтён!» |
| `https://<домен>/?screen=1` | табло, голос из прошлого шага виден |
| `https://<домен>/?admin=1` | вход по коду; цифры «Реальные голоса» совпадают |

Проверять с телефона **через мобильный интернет без VPN**.

После выпуска SSL раскомментировать блок «Всегда по HTTPS» в корневом `.htaccess`.

## 5. Перед шоу

- Пульт → «Удалить все голоса» (стираются тестовые голоса).
- Табло (`?screen=1`) открыть на ноутбуке, вывести на экран, нажать F11.
  В правом нижнем углу — QR-код для зрителей. Скрыть его: `?screen=1&qr=0`.
- Зелёная точка в углу табло — связь есть; красная — нет интернета.

## 6. Старый адрес на GitHub Pages

После запуска заменить `index.html` в репозитории GitHub Pages на переадресацию на новый домен,
чтобы старые ссылки и QR-коды вели на рабочий сайт.

## Как устроен сервер

- `api/index.php?a=vote` — голос (один на устройство, можно переголосовать).
- `api/state.json` — готовое состояние, его опрашивают телефоны (раз в 2,5 с) и табло (раз в 1 с).
  Это статичный файл, поэтому сотни зрителей не нагружают PHP.
- Пульт: вход по коду, сессия 12 часов, после 8 неверных кодов — пауза 15 минут.
- Обновление сайта: заменить файлы и увеличить `?v=` у `style.css`/`app.js` в `index.html`.
